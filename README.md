# 🚗 Vehicle Rental System (Database Project)

## 📌 Project Overview

This project is a **Vehicle Rental System** designed using **RDBMS concepts**.  
The system helps manage vehicle rentals, customers, bookings, payments, and availability in a structured and efficient way.

This project is developed as part of an academic database assignment, following proper database design rules including **ERD, normalization, constraints, and SQL queries**.

---

## 🎯 Project Objectives

- Design a proper **Entity Relationship Diagram (ERD)**
- Implement database tables using **SQL**
- Use **Primary Key, Foreign Key, Constraints**
- Perform **CRUD operations**
- Practice real-life database design concepts

---

## 🛠️ Technologies Used

- Database: **PostgreSQL**
- ERD Tool: **DrawSql**
- SQL Language
- VS Code

---

## 🧩 Database Entities

The system includes the following main entities:

- **Users / Customers**
- **Vehicles**
- **Vehicle Categories**
- **Bookings / Rentals**

---

## 🔗 Relationships (Summary)

- A user can rent multiple vehicles
- A vehicle belongs to one category
- A booking connects users and vehicles
- Each booking can have a payment record

---
